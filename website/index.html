How It Works

A zero-server, cost-efficient hosting architecture built with AWS best practices.

01

Private S3 Bucket

HTML, CSS, and asset files are stored in an Amazon S3 bucket with all public access strictly blocked.

02

CloudFront & OAC

Amazon CloudFront distributes content worldwide using Origin Access Control (OAC) to read from S3 securely.

03

GitHub Actions CI/CD

Every Git commit triggers automated linting, syncs files to S3, and creates an instant CloudFront cache invalidation.

Core Cloud Features

Demonstrating foundational Cloud Engineering and DevOps standards.

🔒

Zero Public S3 Bucket

Public access is 100% disabled via S3 Block Public Access. Only CloudFront's service principal can fetch assets.

⚡

Sub-50ms Global Latency

Edge caching across AWS Point of Presence (PoP) locations ensures lightning-fast delivery worldwide.

🛡️

HTTPS Redirection

Enforces TLS encryption by automatically redirecting all insecure HTTP requests to HTTPS.

🔄

Instant Cache Invalidation

CI/CD pipeline runs aws cloudfront create-invalidation on every deployment so users see updates instantly.
